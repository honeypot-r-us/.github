# Honeypot R Us organization governance

Default community health, agent-project instructions, security policy, and the
canonical ecosystem map for `github.com/honeypot-r-us` and
`github.com/honeypot-r-us-test`.

Planning and coordination:

- Linear project: https://linear.app/denman/project/githubcomhoneypot-r-us-972fb8b3c0fc
- Architecture document: https://linear.app/denman/document/honeypot-r-us-ecosystem-architecture-4b83f9e98375
- Production Slack: https://oresoftware-workspace.slack.com/archives/C0BRVAGPR7D
- Test Slack: https://oresoftware-workspace.slack.com/archives/C0BS3FR7B17

The `.openai/AGENTS.md` and `.claude/CLAUDE.md` files are intentionally
symmetrical. They define equivalent Codex and Claude project context instead of
letting the two agent environments drift into different architectural or
security policies.
